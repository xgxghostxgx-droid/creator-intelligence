Creator Intelligence is a desktop-focused analytics project for creators who want clear insights into their own content performance across multiple platforms.

The TikTok integration is currently in development and is intended to retrieve authorized account information, a user's public video list, and available engagement metrics, subject to TikTok API access.

How data is handled

Creator-owned data

The planned TikTok integration uses user authorization to access permitted account and video information. It is not intended to access other creators' private data.

Manual synchronization

The planned desktop collector lets users initiate synchronization manually, then view saved analytics locally.

Readable analytics

Charts and historical snapshots help compare content performance. Reported metrics may be delayed or unavailable.

Project status

This public website explains a desktop analytics application that is under development. It is not a public hosted analytics service and does not provide account login on this website.
